# UI de bienestar

El HUD muestra estado y puntuación general junto a calidad del agua. El panel desplazable de Detalles contiene filas por pez con especie, puntuación, tendencia, temperatura, volumen, grupo, zona, prioridad y reporte de compatibilidad.

Texto, números y flechas acompañan al color para accesibilidad. La UI se encuentra bajo Safe Area, funciona en horizontal y se actualiza por eventos o intervalos discretos, no mediante formateo por frame.
Las filas pueden mostrar nombre común y científico desde el view model; los datos avanzados respetan el descubrimiento.
