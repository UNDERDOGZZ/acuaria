# Tarjetas de selección

Cada slot conserva un `AquariumInstance` asignado. Nombre, peces y temperatura proceden de esa instancia; nunca se cuentan hijos ni vistas. El color activo se calcula comparando la instancia asignada con `AquariumContext.ActiveAquarium`.

Datos de validación: Acuario Inicial 25 °C y tres peces migrados; Acuario 2 27 °C y un pez; Acuario 3 23 °C y cero peces.
