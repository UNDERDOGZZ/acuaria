# Estilo de código

Se usa C# idiomático, cuatro espacios, llaves en línea separada y un tipo público principal por archivo. Clases, métodos y propiedades usan PascalCase; campos privados usan camelCase; los campos serializados permanecen privados.

Los nombres describen intención, no implementación accidental. Se prefieren funciones pequeñas, composición y dependencias explícitas. Los comentarios explican decisiones o restricciones que el código no puede expresar.

Cada archivo pertenece al namespace de su dominio. Las advertencias del compilador se tratan como señales de diseño y no se silencian sin justificación.
