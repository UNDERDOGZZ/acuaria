# UI provisional del editor

El botón `Editar hábitat` vive dentro del panel Hábitat. El panel inferior respeta Safe Area y deja visible la mayor parte del tanque. Contiene instrucciones, estado, bandeja, Confirmar, Cancelar, Deshacer, Voltear, Rotar y Quitar.

El contorno verde indica candidato válido y el rojo un candidato bloqueado. Confirmar solo se habilita con cambios; las acciones de selección se bloquean sin objeto seleccionado. La UI es funcional y responsive por anchors, pero no representa el polish final.

Mientras está abierto se cancela y bloquea alimentación. Mantenimiento, Diario, Detalles y navegación deben permanecer incompatibles mediante el coordinador de interacción; no se pausa la simulación.
